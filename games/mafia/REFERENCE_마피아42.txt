========================================
마피아42 게임 메커니즘 정리
========================================
(출처: 나무위키 마피아42 / 마피아42-게임 방법 문서 조사)


1. 게임 개요
----------------------------------------
- 한국 개발사 TEAM42가 만든 온라인 마피아 게임 (2014년 출시)
- 4~12명의 플레이어가 참여
- 시민 팀 / 마피아 팀 / 교주 팀(9인 이상, 교주 모드 한정)으로 나뉨
- 각 플레이어는 모두 서로 다른 직업을 하나씩 배정받음
- 사회자는 없으며 시스템이 자동으로 게임을 진행
- 게임은 낮과 밤을 번갈아 진행하며, 처음은 "밤"부터 시작


2. 밤 페이즈 (25초)
----------------------------------------
- 밤 능력을 가진 직업은 능력 사용 대상을 지정
- 마피아들은 합의를 통해 죽일 사람 한 명을 지정

[비밀 채팅]
- 마피아 + 마피아팀 보조직업: 팀 전용 대화 가능
  (단, 보조직업은 마피아와 '접선'한 이후에만 대화 가능)
- 연인(2인): 서로 대화 가능
- 영매: 죽은 사람들을 향해 말할 수 있음
- 교주/광신도: 교주팀에게 일방적으로 메시지 전송 가능
- 이 비밀 대화들은 죽은 사람들에게 노출됨
  (경찰/사립탐정/해커는 '도청' 능력으로 엿볼 수 있음)

[포교]
- 홀수 번째 밤에는 교주가 플레이어 1명을 포교 가능
- 포교 성공 시 "교주의 종소리가 울려퍼졌습니다." 알림이 전체에게 전송됨
- 마피아, 성직자는 포교 불가


3. 낮 페이즈
----------------------------------------
[3-1. 결과 발표 + 토론 시간] (생존자 수 x 15초)
- 밤 능력 사용 결과 공개 (누가 죽었는지 등)
- 아무도 죽지 않은 경우 "조용하게 밤이 지나갔습니다." 출력
  * 짐승인간/사기꾼을 공격했거나, '은폐' 능력으로 의사의 치료 사실이나
    군인의 방탄 사실을 숨긴 경우에도 같은 문구가 출력됨
- 결과 발표 후 짧은 채팅 금지 시간이 지나면 전체 채팅 가능
- 모든 생존자는 하루 1회 토론 시간을 15초 연장 또는 단축 가능
- 여론 조사: 토론 중 한 명을 지목할 수 있음
  * 누가 지목했는지는 비공개, 몇 표를 받았는지만 표시
  * 실제 게임 진행에는 영향 없는 여론 확인용
- 일부 직업(심리학자, 해커, 사기꾼)은 토론 시간에 능력 사용

[3-2. 투표 시간] (15초)
- 1인 1표 (정치인은 2표로 인정, 표시상으로는 1표)
- 투표 종료 전까지 대상 변경 가능, 마지막 투표가 최종 반영
- 자기 자신에게 투표하는 '자투'도 가능
- 실시간 득표 현황 표시 -> 종료 5초 전 비공개 전환
- 최다 득표자 1명 -> 최후의 반론으로 진행
- 동률이거나 아무도 투표 안 함 -> 처형 없이 바로 밤으로

[3-3. 최후의 반론] (15초)
- 최다 득표자만 채팅 가능한 변론 시간

[3-4. 찬반 투표] (5초)
- 과반수 찬성 -> 처형
- 반대가 더 많음 -> 처형 없이 밤으로
- 찬반 동수 -> 처형됨
- 누가 찬성/반대했는지 비공개
- 판사가 있으면 찬반 결과와 무관하게 판사의 결정이 우선


4. 사망자 규칙
----------------------------------------
- 죽은 플레이어는 능력 사용 불가, 투표 불가, 투표 대상도 될 수 없음
  (단, 죽음이 발동 조건인 직업 제외: 과학자, 마술사 등)
- 죽은 사람들끼리만 보이는 채팅 가능 (낮/밤 무관)
- 영매는 죽은 사람들의 채팅을 볼 수 있음
- '성불' 상태가 되면 채팅이 보이지 않게 되고 부활 불가


5. 승리 조건
----------------------------------------
[판정 시점]
- 하루 2번: 밤 -> 낮 전환 시점, 찬반투표 종료 -> 밤 전환 시점
- 동시 충족 시 우선순위: 마피아팀 > 시민팀 > 교주팀
- 랭크게임 한정: 10번째 밤이 지나면 마피아팀 자동 승리

[클래식/일반 모드]
- 마피아팀 승리: 마피아팀 머릿수 >= 시민팀 머릿수
- 시민팀 승리: 모든 마피아팀 사망
  * 접선하지 않은 보조직업은 마피아 머릿수로 계산되지 않으므로
    마피아만 전부 죽이면 시민 승리 가능
- 즉시 승리 능력: 예언자의 '계시', 비밀결사의 '밀사' 등

[교주 모드]
- 마피아팀: 마피아팀 머릿수 >= 시민팀+교주팀 머릿수
- 시민팀: (1) 모든 마피아팀 및 교주(+능력 계승 광신도) 제거
          (2) 시민팀 머릿수 >= 교주팀 머릿수 를 순서대로 만족
- 교주팀(교주 생존 시): 모든 마피아팀 사망 + 교주팀 머릿수 >= 시민팀 머릿수
- 교주팀(교주 사망 시): 모든 마피아팀 사망 + 모든 시민팀 제거
- 포교된 플레이어는 교주팀과 승리 조건을 공유 (교주가 지면 같이 패배)

[머릿수 특수 판정]
- 정치인: 머릿수/투표권 2로 계산
- 건달: 머릿수 3으로 계산
- 예언자: 본인 생존 시 게임이 끝나지 않음
- 판사: 찬반 결과를 뒤집어 정체를 드러내면 머릿수/투표권 무한
- 용병: 의뢰인 사망으로 처형 능력 활성화 시 본인 사망 전까지 게임 지속
- 비밀결사(2인): 둘 다 생존 시 게임이 끝나지 않음


6. 직업 구성
----------------------------------------
[중요 직업 - 클래식 등장]
- 마피아: 밤마다 1명 처형 (마피아팀의 핵심)
- 경찰: 조사 능력 (시민팀 핵심)
- 의사: 치료 능력 (시민팀 핵심)
- 자경단원, 요원, 형사

[마피아팀 보조직업] (마피아와 '접선' 후 협력)
- 스파이, 짐승인간, 마담, 도둑, 마녀, 과학자,
  사기꾼, 청부업자, 대부, 악인

[시민팀 특수직업]
- 군인(방탄), 정치인(투표 2표/투표 처형 면역), 영매(사자 채팅 열람),
  연인(2인 배정), 건달, 기자, 사립탐정, 도굴꾼, 테러리스트(자폭),
  성직자(소생), 예언자, 판사, 간호사, 마술사, 해커, 심리학자,
  용병, 공무원, 비밀결사(2인 배정), 파파라치, 최면술사, 점쟁이, 시민

[교주팀] (9인 이상 교주 모드)
- 교주: 홀수 밤마다 포교
- 광신도: 교주의 능력을 이어받을 수 있음


7. 기타 시스템 참고
----------------------------------------
- 일반게임에서 2번째 밤 전에 승패가 결정되면 해당 판은 무효 처리
- 랭크 게임: 8인 매칭, RP(랭크 포인트) 시스템,
  우드~그랜드마스터 등급, 마피아팀은 승패 시 RP 변동 폭이 더 큼
- 게임 모드: 클래식 모드, 듀얼 모드(카드/스킬 사용), 교주 모드 등
