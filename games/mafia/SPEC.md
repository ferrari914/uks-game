# 마피아 (Englknight) — 제작 스펙 v1

> 원본 조사 자료: `REFERENCE_마피아42.txt` (마피아42 메커니즘 정리)
> 이 스펙은 그 자료를 **정적 웹사이트 / 싱글플레이**로 옮기기 위해 축소·확정한 것이다.

## 0. 왜 싱글플레이인가
Englknight는 GitHub Pages 정적 배포다. 마피아는 밤 능력·비밀채팅 때문에
서버 권위(authority)가 없으면 멀티가 성립하지 않는다(클라이언트가 모든 정체를 알게 됨).
따라서 v1은 **플레이어 1명 + AI 7명 = 8인 클래식전**으로 만든다.
멀티는 별도 백로그(서버 필요).

- 교주 모드(9인 이상), 마피아 보조직업, 듀얼 모드는 v1 범위 밖.
- 직업은 매판 랜덤 배정, 플레이어도 무작위(마피아가 걸릴 수 있음).

### 직업 능력
- **마피아**: 밤마다 1명 지목 → 사망. 마피아끼리 밤에 비밀 채팅. 서로의 정체를 안다.
- **경찰**: 밤마다 1명 조사 → "마피아다 / 마피아가 아니다" 판정.
- **의사**: 밤마다 1명 치료 → 그 밤의 마피아 공격 1회 무효. 자가치료 가능.
- **군인**: 방탄 1회. 첫 마피아 공격을 자동으로 버틴다(2회째부터 사망). 능력 지목 없음.
- **정치인**: 투표 2표(표시는 1표). 투표 처형 면역(최다 득표·찬성 과반이어도 처형되지 않음, 1회성 아님 — 마피아42 기준 처형 면역). 승리 판정 머릿수 2로 계산.
- **영매**: 사망자 채팅을 볼 수 있다. 밤 지목 없음.
- **시민**: 능력 없음. 토론·투표만.

## 2. 진행 순서 (밤부터 시작)
1. **밤** (25초) — 능력 지목. 마피아 비밀채팅. 플레이어가 능력 없는 직업이면 대기.
2. **결과 발표** — 사망자 공개. 아무도 안 죽으면 "조용하게 밤이 지나갔습니다."
   (의사 치료·군인 방탄으로 막혔을 때도 같은 문구 — 정보를 흘리지 않는다)
3. **토론** (생존자 수 × 15초) — 전체 채팅. AI가 발언. 플레이어도 입력 가능.
   - 하루 1회 토론시간 15초 연장/단축 버튼
   - 여론조사: 1명 지목 가능, 득표수만 공개(누가 눌렀는지 비공개), 진행에 영향 없음
4. **투표** (15초) — 1인 1표(정치인 2표), 변경 가능, 자기 자신 투표 가능.
   실시간 득표 표시 → **종료 5초 전 비공개 전환**.
   - 최다 득표 1명 → 최후의 반론
   - 동률 / 아무도 투표 안 함 → 처형 없이 밤으로
5. **최후의 반론** (15초) — 지목된 사람만 발언(플레이어면 입력창, AI면 변론 대사)
6. **찬반 투표** (5초) — 과반 찬성 → 처형 / 반대 다수 → 생존 / **동수 → 처형**.
   누가 찬성·반대했는지 비공개. 정치인은 여기서 처형 면역이 발동한다.
7. → 밤으로 반복

## 3. 사망자 규칙
- 사망 시 능력·투표 불가, 투표 대상도 안 됨.
- 사망자 전용 채팅(낮·밤 무관). 영매는 이 채팅을 읽을 수 있다.
- 플레이어가 죽어도 게임은 계속 관전(사망자 채팅 참여) → 최종 결과까지 본다.
- 죽은 사람의 직업은 공개하지 않는다(마피아42 클래식 기준 — 시체 직업 비공개).

## 4. 승리 판정
- 판정 시점: **밤→낮 전환 직후**, **찬반투표 종료→밤 전환 직전** (하루 2회)
- 마피아팀 승리: 마피아 머릿수 ≥ 시민팀 머릿수
- 시민팀 승리: 마피아 전원 사망
- 머릿수 특수: 정치인은 2로 계산
- 동시 충족 시 마피아팀 우선

## 5. AI 설계 (핵심 — 여기가 게임의 재미다)
각 AI는 다른 생존자에 대한 **의심도(0~100)** 를 들고 다닌다.
- 시민팀 AI: 로그(투표 이력, 사망자와의 상호작용, 주장 일관성)로 의심도를 갱신
- 마피아 AI: 동료를 알고 있으므로 동료 의심도를 낮추고, 위협적인 시민(경찰 주장자 등)을 지목
- 경찰 AI: 조사 결과를 며칠 뒤 또는 위급할 때 커밍아웃
- 발언은 템플릿 + 상태값 조합(예: "{이름} 어제 투표가 이상한데?", "저 경찰입니다. {이름} 마피아 확정")
- 투표는 의심도 최고값 + 약간의 랜덤. 찬반은 자기 의심도 기준.
- **플레이어 커밍아웃/주장에 AI가 반응해야 한다** (예: 플레이어가 "경찰"이라 치면 진짜 경찰 AI가 반박)

## 6. UI/기술 요건
- **단일 파일** `games/mafia/index.html` (HTML+CSS+JS 인라인). 외부 라이브러리·CDN 금지.
- `file://` 더블클릭으로도 동작해야 한다 (fetch/모듈 import 금지).
- 다크 아케이드 테마, 테트리스/OX와 톤 통일:
  `--bg:#0a0d16; --panel:#141a2b; --panel2:#1b2338; --line:#28324f; --text:#e8ecf7; --muted:#8b95b3`
  마피아 액센트는 붉은 계열(예: `#ff4d6d`) + 밤/낮 배경 전환 연출
- 모바일 세로 우선(max-width 460px 스테이지), 안전영역(env(safe-area-inset-*)) 대응
- 채팅 로그가 주 화면. 상단에 페이즈·타이머·생존자 목록, 하단에 입력/능력 지목 UI
- 타이머는 실제 흐르되 **"건너뛰기" 버튼** 제공(싱글플레이라 기다릴 이유가 없다)
- 게임 종료 시 전원 직업 공개 + 다시하기
- 좌상단에 허브 복귀 링크(`../../index.html`)
- 규칙 설명(도움말) 모달 1개 — 직업 능력 요약
