# 오목 (렌주룰) — 1:1 온라인 대전

방 코드 하나로 **두 사람**이 각자 기기에서 두는 오목. Englknight의 멀티 게임 중
유일하게 **정확히 2명**을 위한 게임이다 (나머지는 전부 다수 인원이 필요하다).

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 · 통신 |
| `renju.js` | **규칙 엔진** (금수·승패 판정). 화면과 분리돼 있다 |
| `test-renju.js` | 규칙 엔진 검증 (개발용, 게임 실행에는 쓰이지 않는다) |
| `SPEC.md` | 확정 스펙 |

> **두 파일은 같은 폴더에 함께 있어야 한다.** `renju.js`가 없으면 판정을 할 수 없으므로
> 게임이 시작되지 않고 안내 문구가 뜬다.

## 규칙 (렌주룰)

- 15×15. 흑 선공.
- **흑**: 정확히 **5목**만 승리. **삼삼 · 사사 · 장목(6목 이상)은 금수**
- **백**: 제한 없음. 5목 이상이면 승리
- **5목이 되는 수는 금수보다 우선한다** — 그 수로 삼삼이 동시에 나도 흑의 승리
- 렌주 정식 개시 규칙(주형·5수 다타)은 넣지 않았다. 대신 **재대국마다 선/후공 교대**

### 금수를 화면에 표시한다
렌주룰의 유일한 위험은 "여기 왜 안 놓아져요?"다. 그래서 흑 차례에는 **금수 자리에 붉은 ✕**를
미리 그리고, 눌러보면 사유(삼삼/사사/장목)를 알려주며 착수 자체를 막는다.
(정식 렌주는 금수를 두면 즉시 패배지만, 친구끼리 두는 판에서 실수 한 번에 게임이 끝나는 건
재미가 아니다.)

## 조작
15×15는 칸이 손가락보다 작다. **탭 한 번에 확정하면 반드시 오착이 난다.**
1. 빈 칸 탭 → 반투명 미리보기 돌 + 좌표 표시(`K8`)
2. 같은 칸 다시 탭하거나 **놓기** → 확정

## 통신
- 공용 MQTT 브로커(emqx / hivemq / mosquitto) 3곳을 순회한다. 서버는 없다
- 토픽 `okm1/<방코드>/state`(retain) · `okm1/<방코드>/ev`
- **방장 브라우저가 판의 주인**이다. 착수 합법성·승패 판정은 방장만 한다
- `state`가 retain이라 **끊겼다 돌아오면 브로커에서 현재 판을 받아 그대로 복구**된다

### 끊김 처리 — 몰수패는 없다
공용 브로커는 주기적으로 연결을 강제 절단한다. 시간패를 넣으면 억울한 패배가 나온다.
대신 상황을 알리고 빠져나올 길을 연다.

| 무응답 | 표시 | 선택지 |
|---|---|---|
| 15초 | `연결 불안정` | — |
| 40초 | `응답 없음` + 안내 | **무승부로 종료** · **방 나가기** |

돌아오면 그대로 이어진다. 방장이 나가면 방이 끝난다(v1은 방장 승계 없음).

## 규칙 엔진 테스트

이 환경에는 node가 없어 macOS 내장 JavaScriptCore로 돌린다.

```bash
cat renju.js test-renju.js > /tmp/r.js && osascript -l JavaScript /tmp/r.js
```

node가 있으면:

```bash
node -e "global.RENJU=require('./renju.js');require('./test-renju.js')"
```

25개 케이스가 승부 판정(판 가장자리·모서리 대각·**행 경계를 넘어 세는 오판**·6목·끊긴 4+1)과
금수 판정(삼삼·사사·**열린사를 사사로 오판하지 않는가**·한 줄 이중사·장목·5목 우선)을 덮는다.

## 알려진 한계
- **`file://` 더블클릭은 미검증.** 개발 환경의 브라우저 도구가 `file://`을 data: 스냅샷으로
  바꿔 열어 실제 확인이 불가능했다. classic script는 file://에서도 형제 파일을 읽으므로
  동작할 것으로 보지만 **추측이다.** 사용자 확인이 필요하다
- 전적은 새로고침하면 초기화된다 (서버가 없다)
- 관전자·채팅·기보 저장·AI 싱글은 v1 범위 밖
