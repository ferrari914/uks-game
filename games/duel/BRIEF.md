# 1:1 대전 보드게임 — 착수 브리프

> 게임 관리자 작성 / 2026-08-28
> **이 문서는 방향 제시이지 확정 스펙이 아니다.** 담당이 조사·판단해 `SPEC.md`를 만들고
> 게임 관리자 검수를 받은 뒤 구현에 들어간다.

## 사용자 요구
"1:1 대전 보드게임" — 종목은 담당이 정한다.

## 왜 이 게임인가 (프로젝트 맥락)
지금 멀티 게임은 전부 **다수 인원**이 필요하다.
- OX 서바이벌: 여러 명
- 마피아: 4~8인
- 캐치마인드: 2~8인이지만 그림 퀴즈라 인원이 많을수록 재미있다
- 라이어: 3~10인 오프라인 파티

**둘이서 붙을 게임이 하나도 없다.** 친구 한 명과 할 게 없다는 뜻이다. 이 게임이 그 자리다.

## 방향 후보 (담당이 골라 확정)
1. **오목** — 규칙이 익숙하고 구현이 확실하다. 렌주룰(금수) 적용 여부가 판단 포인트
2. **커넥트4** — 더 가볍고 판이 빨리 끝난다. 모바일 화면에 잘 맞는다
3. **그 외** — 담당이 더 나은 것을 찾으면 근거와 함께 제안할 것

## 기술 제약 (반드시 지킬 것)
- GitHub Pages 정적 배포. **서버 없음**
- 멀티는 공용 MQTT 브로커 + **방장 브라우저 권위** 모델 (`games/ox-survival/index.html` 참고)
- **턴제라 이 환경에 가장 안전하다.** 한 수 두면 상대에게 전달되는 구조라 지연이 문제되지 않는다
- `file://` 더블클릭에서 페이지가 열려야 한다. ES 모듈 금지, classic script

## 함께 고려할 것
- **혼자서도 할 수 있게 만들지 판단할 것.** 상대가 없으면 못 노는 게임은 접속했다가
  그냥 나가게 된다. 마피아 v2가 싱글+멀티 둘 다 넣은 이유가 그것이다.
  AI 상대를 넣는다면 난이도가 납득되게 — 무작위로 두면 게임이 아니라 주사위가 된다
- **승부 판정이 정확해야 한다.** 오목의 금수·6목 처리, 무승부 조건 등을 스펙에 명시할 것

## 산출물
`games/duel/` 안에서만 작업한다. 허브 등록(`data/games.js`)은 메인 홈페이지 담당 관할이니
직접 건드리지 말고, 완성 시 게임 관리자에게 한 줄 설명·태그를 넘긴다.

> 폴더명이 `duel`인 것은 종목이 아직 안 정해졌기 때문이다. 종목 확정 후 폴더명을 바꾸고
> 싶으면 게임 관리자에게 요청할 것(허브 경로와 맞물려 있어 임의 변경 금지).
