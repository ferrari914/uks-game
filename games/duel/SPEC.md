## 2. 규칙 (승부 판정) — **렌주룰**

> 2026-08-28 사용자 확정: **금수를 넣는다. 렌주룰로 간다.**
> (담당이 처음 제안한 자유룰은 사용자 판단으로 기각됨)

| 항목 | 확정 |
|---|---|
| 판 | **15×15** (화점 5개 표시) |
| 선공 | **흑 선공.** 흑에게만 금수가 걸린다 |
| 흑 승리 | **정확히 5목**. 6목 이상(장목)은 승리가 아니라 **금수** |
| 백 승리 | **5목 이상.** 백에게는 금수도 장목 제한도 없다 |
| 흑 금수 | **삼삼 · 사사 · 장목** 3종 |
| 우선순위 | **5목이 되는 수는 금수보다 우선한다.** 그 수로 삼삼이 동시에 나도 흑의 승리 |
| 무승부 | 225칸이 다 차고 5목이 없을 때 |
| 개시 규칙 | 렌주 정식 개시(주형·5수 다타 등)는 **넣지 않는다.** 초심자에게 진입장벽이 너무 크다. 대신 재대국 시 선/후공을 교대한다 |

### 금수를 화면에 표시한다 (필수)
"여기 왜 안 놓아져요?"를 없애는 것이 렌주룰 도입의 유일한 위험이다. 그래서:
- 흑 차례일 때 **금수 자리에 붉은 ✕를 미리 표시**한다. 두기 전에 보인다
- 금수 자리를 탭하면 **이유를 말로 알려준다** — `삼삼은 둘 수 없습니다` / `사사` / `여섯 목(장목)`
- 착수 자체를 **막는다.** (정식 렌주는 금수를 두면 즉시 패배지만, 친구끼리 두는 판에서
  실수 한 번에 게임이 끝나는 건 재미가 아니다. 막고 알려주는 쪽을 택한다)
- 규칙 도움말 버튼을 상시 노출한다

### 금수 판정 알고리즘 (구현 지침)
용어는 RIF 렌주 규칙을 따른다.
- **오(五)**: 정확히 5 연속 / **장목**: 6 이상 연속
- **사(四)**: 한 수를 더 두면 오가 되는 형태. 오가 되는 지점이 2개면 **열린사**
- **삼(三)**: 한 수를 더 두면 **열린사**가 되는 형태. 단 그 한 수를 두는 지점이
  **흑에게 금수가 아니어야** 한다 (← 여기서 재귀가 발생한다)

판정 순서 (흑이 (x,y)에 둔다고 가정):
1. 정확히 5목이 되면 → **승리.** 금수 검사를 하지 않는다
2. 6목 이상이 되면 → **장목 금수**
3. **사의 개수 ≥ 2 → 사사 금수**
4. **삼의 개수 ≥ 2 → 삼삼 금수**

**사를 셀 때 주의 (최다 버그 지점):** 개수를 "오가 되는 빈 점의 수"로 세면
열린사 `.●●●●.`가 양끝 2개로 잡혀 **사사로 오판**된다. 열린사는 하나의 사다.
→ 오가 되는 빈 점마다 **그 오를 이루는 돌 4개의 집합**을 구해 **집합 기준으로 중복 제거**한다.
   같은 돌 4개를 쓰면 같은 사다. 한 줄 안의 진짜 이중사는 돌 집합이 달라 2로 세어진다.

**삼을 셀 때 주의:** 재귀가 순환할 수 있으므로 **깊이 상한**을 두고, 상한에 닿으면
그 지점을 금수가 아닌 것으로 보고 되돌아온다(실전에서 깊이 3을 넘는 경우는 없다).

### 구현·검증 방식
금수 판정은 눈으로 봐서 맞는지 알 수 없다. 그래서:
- 규칙 엔진을 **`renju.js`로 분리**한다 (classic script, `window.RENJU`에 노출)
- **`test-renju.js`(node 실행)로 기보 케이스를 돌려 검증**하고 결과를 보고에 첨부한다
- 화면 코드와 규칙 코드를 섞지 않는다 — 섞으면 판정을 고칠 때마다 UI가 깨진다

## 3. 화면 흐름

```
[홈] ─┬─ 방 만들기 → 6자리 코드 발급 → [대기실] ─┐
      └─ 코드 입력해 참가 ────────────────────────┴→ [대국] → [결과] → 재대국/나가기
```

- **홈**: 닉네임 입력(최대 8자), `방 만들기` / `참가하기`. URL 해시(`#ABC123`)로 들어오면 코드 자동 입력
- **대기실**: 방 코드 크게 표시 + `초대 링크 복사` 버튼. 상대가 들어오면 방장이 `시작`
- **대국**: 판 + 상단에 양쪽 이름·돌 색·현재 차례. 하단에 `무르기 요청` `기권`
- **결과**: 승자·승리 라인 강조 표시(5목을 이은 돌을 빛나게). `한 판 더`(선후공 교대) / `나가기`

## 4. 착수 조작 (모바일 오착 방지 — 중요)
15×15는 손가락보다 칸이 작다. **탭 한 번에 확정하면 반드시 오착이 난다.**

1. 빈 칸을 탭 → 그 자리에 **반투명 미리보기 돌** + 좌표 표시(예: `H8`)
2. 같은 칸을 다시 탭하거나 하단 `놓기` 버튼 → **확정**
3. 다른 칸을 탭하면 미리보기가 그리로 이동, 바깥을 탭하면 취소

확정된 수는 되돌릴 수 없다(무르기는 상대 동의 필요).
마지막에 놓인 돌에는 항상 **표식**을 남겨 상대가 어디에 뒀는지 즉시 보이게 한다.

## 5. 부가 기능
- **무르기 (v1 포함)**: **직전 1수만**, **상대가 수락해야** 취소된다. 일방적 무르기는 없다
  (일방적이면 오목이 성립하지 않는다). **판당 각자 3회까지**, 요청 중에는 착수가 잠긴다.
  상대가 무응답이면 요청자가 스스로 취소할 수 있다
- **기권**: 확인 한 번 받고 즉시 패배 처리
- **재대국**: 양쪽 모두 `한 판 더`를 누르면 시작. 선/후공 교대
- **누적 전적**: 방이 유지되는 동안 `2 : 1` 식으로 표시(새로고침하면 초기화 — 서버가 없다)
- 채팅은 **v1 범위 밖.** 대국 자체를 확실히 굴린 뒤 v1.1에서 판단한다

## 6. 통신 설계

### 재사용
`games/ox-survival/index.html`의 `makeMqttNet()`을 **그대로 가져온다.**
공용 브로커 3곳 순회 + 절단 시 다음 브로커 승격 + 탭 숨김 예외 처리까지 이미 검증된 코드다.
clientId 접두사만 `ok_`로 바꾼다.

### 토픽
```
okm1/<코드>/state   (retain)  방장 → 전체. 판 전체 상태
okm1/<코드>/ev                참가자 → 방장. 착수·무르기·기권 등 요청
```
`state`를 **retain**으로 두는 것이 핵심이다. 늦게 들어오거나 끊겼다 돌아온 쪽이
브로커에서 현재 판을 즉시 받아 그대로 복구된다.

### 권위 모델
**방장 브라우저가 판의 주인**이다. 참가자는 "여기 두고 싶다"를 보낼 뿐이고,
합법 여부(빈 칸인가, 내 차례인가) 판정과 승패 판정은 **방장만** 한다.
양쪽이 각자 판정하면 어긋났을 때 화해시킬 방법이 없다.

state에는 착수 목록(`moves`)을 담아 보낸다 — 225칸 배열보다 작고, 기보 복원·무르기가 자연스럽다.

### 끊김 처리
**억울한 패배를 안 만드는 것과, 못 빠져나오게 가두는 것은 다른 문제다.** 몰수패는 넣지 않되,
사람이 상황을 알고 스스로 결정할 수 있게 한다. 3단계로 알린다:

| 무응답 시간 | 표시 | 열리는 선택지 |
|---|---|---|
| 15초 | `상대 연결이 불안정합니다…` | (없음. 그냥 대기) |
| 40초 | `상대가 나간 것 같습니다` | **`무승부로 종료`** · **`방 나가기`** 버튼 노출 |
| 복귀 시 | 표시 사라지고 그대로 속행 | — |

- **시간 초과 몰수패는 넣지 않는다.** 공용 브로커는 주기적으로 강제 절단하므로
  억울한 패배가 나온다. 끝내려면 사람이 `기권`·`무승부로 종료`를 누른다
- 방장이 나가면 방이 끝난다(참가자에게 `방장이 나갔습니다` + 나가기 버튼). v1은 방장 승계 없음

## 12. 검수용 경계 조건 (구현 후 직접 확인할 목록)
승부 판정이 이 게임의 전부다. 아래를 전부 만들어 확인한 뒤 보고한다.
1. **판 가장자리 5목** — 맨 윗줄·맨 아랫줄·좌우 끝열의 가로/세로 5목
2. **모서리 대각선** — (0,0)→(4,4), (14,0)→(10,4) 양방향 대각
3. **경계를 넘는 오판** — 우측 끝(x=14)에서 다음 줄 좌측(x=0)으로 이어져 5목으로 잘못 세는가
   (1차원 배열로 구현할 때 가장 흔한 버그)
4. **6목** — 5개 이상이면 승리로 인정되는가
5. **끊긴 4+1** — `●●●●○●` 처럼 사이가 막힌 배치를 승리로 오판하지 않는가
6. **동시 판정** — 마지막 한 칸을 채우며 5목이 났을 때 무승부가 아니라 승리로 처리되는가
7. **차례 위반** — 내 차례가 아닐 때 보낸 착수 요청을 방장이 거부하는가
8. **중복 착수** — 이미 돌이 있는 칸, 같은 수를 두 번 보냈을 때
9. **금수 — 삼삼**: `.●●.●.` 류 실제 삼삼 자리를 금수로 잡는가
10. **금수 — 사사**: 서로 다른 두 방향의 사, 그리고 한 줄 안의 이중사
11. **열린사 오판 금지**: `.●●●●.`(열린사)를 사사로 잘못 잡지 않는가 ← 최우선 확인
12. **거짓 삼 배제**: 막힌 삼(`○●●●.`)을 삼으로 세지 않는가
13. **5목 우선**: 삼삼이면서 동시에 5목이 되는 수를 **승리**로 처리하는가
14. **백은 자유**: 백의 삼삼·사사·6목이 전부 정상 허용되는가 (6목은 백의 승리)
15. **장목**: 흑이 6목을 만드는 수가 금수로 막히는가
