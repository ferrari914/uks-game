# OX 서바이벌 — 배포 안내

`index.html` 파일 하나가 전부입니다. 빌드도, 서버도, 계정도 필요 없습니다.

## 가장 빠른 방법: Netlify Drop (1분)

1. https://app.netlify.com/drop 접속
2. `index.html`이 들어 있는 폴더를 통째로 드래그해서 놓기
3. `https://무작위이름.netlify.app` 주소가 바로 생성됨
4. 그 주소를 카톡 단톡방에 올리기

로그인 없이도 배포되지만, 계정을 만들면 주소를 원하는 이름으로 바꿀 수 있습니다.

## 대안

| 방법 | 절차 |
|---|---|
| **GitHub Pages** | 저장소 만들고 `index.html` 업로드 → Settings → Pages → Branch `main` / `root` 선택 |
| **Cloudflare Pages** | Direct Upload로 폴더 업로드 |
| **Vercel** | 프로젝트 생성 후 정적 폴더 배포 |

셋 다 무료이고 HTTPS가 자동으로 붙습니다. **HTTPS는 필수입니다** — WebSocket 연결이 `wss://`라서 `http://`나 `file://`로 열면 브라우저가 차단합니다. 파일을 더블클릭해서 여는 방식으로는 멀티플레이가 안 됩니다.

## 노는 순서

1. 한 명이 접속해서 이름·캐릭터를 고르고 **새 방 열고 초대 링크 받기**
2. **초대 링크 복사** → 단톡방에 붙여넣기 (`.../#8F7BR` 형태로 방 코드가 링크에 박힘)
3. 친구들이 링크를 누르면 "초대받은 방 8F7BR" 카드가 뜨고, 이름만 넣고 **바로 입장**
4. 방장이 문제 수(5~20)와 제한시간(8~20초)을 고르고 시작

## 동작 방식

참가자끼리는 공용 MQTT 브로커(WebSocket)로 연결됩니다. 순서대로 시도하며, 앞의 것이 막히면 자동으로 다음으로 넘어갑니다.

1. `broker.emqx.io`
2. `broker.hivemq.com`
3. `test.mosquitto.org`

방장의 브라우저가 심판 역할을 합니다. 문제 진행, 정답 판정, 탈락 처리를 전부 방장 기기에서 계산해 나머지에게 뿌립니다.

## 알아둘 점

- **방장이 창을 닫으면 방이 닫힙니다.** 방장은 게임 중에 탭을 끄지 마세요.
- 공용 브로커는 누구나 접속할 수 있는 공개 서버입니다. 방 코드는 5자리(약 3,300만 조합)라 우연히 겹칠 일은 거의 없지만, 민감한 내용은 이름이나 문제에 넣지 마세요.
- 카톡 인앱 브라우저에서도 동작하지만, 불안정하면 우측 하단 메뉴에서 **다른 브라우저로 열기**를 쓰세요.
- 12초 넘게 응답이 없는 참가자는 자동으로 목록에서 빠집니다. 잠깐 끊겼다가 돌아오면 다시 합류합니다.
- 게임 도중 들어온 사람은 관전만 하다가 다음 판부터 참가합니다.

## 문제 추가하기

`index.html` 안의 `QUESTIONS` 배열에 한 줄 추가하면 끝입니다.

```js
{q:'우리 중에 지각을 제일 많이 한 사람은 성돈이다.',a:'O'},
```

`a`는 `'O'` 또는 `'X'`. 저장하고 다시 올리면 반영됩니다.
