> 게임 관리자 작성 / 2026-08-28
> **이 문서는 방향 제시이지 확정 스펙이 아니다.** 담당이 조사·판단해 `SPEC.md`를 만들고
> 게임 관리자 검수를 받은 뒤 구현에 들어간다.

## 사용자 요구
"영어 단어 배틀" — 세부는 담당이 정한다.

## 왜 이 게임인가 (프로젝트 맥락)
사이트 이름이 **Englknight** = English + knight, "영어를 쓰는 기사"다.
CLAUDE.md에 명시된 컨셉은 *"나만의 캐릭터를 키우는 RPG"* 이고 미니게임은 성장 수단이다.

**지금 5개 게임 중 사이트 이름과 정면으로 맞는 게임이 없다.** 테트리스에 부활 영어 퀴즈가
붙어 있는 정도다. 이 게임이 그 자리를 메우는 역할이다.

## ⚠ 종목 확정 — 영어 끝말잇기 (2026-08-28)
**사용자님이 담당 세션을 "영어 끝말잇기 담당"으로 직접 지정하셨습니다.**
아래 3안 중 고르는 단계는 **이미 끝났습니다.** 2안(영어 끝말잇기)으로 확정이며,
다음에 이 문서를 읽는 사람은 다시 고민하지 않아도 됩니다.

## 방향 후보 (참고용 — 선택은 이미 끝남)
1. **단어 만들기** — 제시된 글자 조합으로 최대한 많은/긴 단어 만들기, 제한시간
2. **영어 끝말잇기** — 앞 단어의 마지막 글자로 시작하는 단어. 한국식 끝말잇기의 영어판
3. **뜻 맞히기 속도전** — 단어를 보고 뜻을 고르는 반응 속도 대결

## 기술 제약 (반드시 지킬 것)
- GitHub Pages 정적 배포. **서버 없음**
- 멀티는 공용 MQTT 브로커 + **방장 브라우저 권위** 모델 (`games/ox-survival/index.html` 참고)
- **턴제로 설계하면 기술적으로 안전하다.** 실시간 위치·충돌 동기화가 들어가면 공용 브로커
  지연(수백ms) 때문에 억울한 판정이 생긴다
- 단어 사전은 외부 API를 쓸 수 없다 → **단어 목록을 파일로 내장**해야 한다
  (캐치마인드 `words.js`가 400개 내장한 선례 참고)
- `file://` 더블클릭에서 페이지가 열려야 한다. ES 모듈 금지, classic script

## 유의할 점
- **단어 판정이 이 게임의 핵심 리스크다.** 내장 사전에 없는 정당한 단어를 거부하면
  플레이어가 바로 떠난다. 사전 규모와 판정 규칙을 먼저 정하고 시작할 것
- 저작권: 사전 데이터 출처를 확인하고 문제 없는 것만 쓴다

직접 건드리지 말고, 완성 시 게임 관리자에게 한 줄 설명·태그를 넘긴다.
