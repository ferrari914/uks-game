# 무한의 계단 (Infinite Stairs)

버튼 두 개로 계단을 무한히 오르는 아케이드. 혼자 최고 층수에 도전하는 **싱글**과,
한 명 남을 때까지 겨루는 **멀티**가 있다.

- 스펙: [SPEC.md](SPEC.md) — 수치·규칙의 근거는 전부 여기 있다
- 원작 조사: [REFERENCE_무한의계단.txt](REFERENCE_무한의계단.txt) (게임 관리자 작성)
- 파일: `index.html` 하나. classic script만 쓰므로 **더블클릭(`file://`)으로도 열린다.**

## 조작

| | |
|---|---|
| **오르기** | 지금 바라보는 방향 그대로 한 칸 |
| **방향 전환** | 몸을 돌리면서 **동시에** 한 칸 |

다음 계단이 지금 방향과 **같으면 오르기**, **반대면 방향 전환**. 잘못 누르면 벽에 부딪혀 즉사한다.

- PC: `Z`·`↑` = 오르기 / `X`·`←`·`→` = 방향 전환
- 모바일: 화면 아래 왼쪽 = 방향 전환, 오른쪽 = 오르기

## 체력 게이지

가만히 있으면 닳고, 한 칸 오를 때마다 회복한다. **멈추면 죽는다.**

```
초당 감소 D(f) = 22 + 53 × ∛( min(1, f/2000) )      한 칸당 회복 +12
```

| 층 | 1초 망설이면 | 유지에 필요한 속도 |
|---|---|---|
| 1 | −26% | 2.2 칸/초 |
| 50 | −38% | 3.1 칸/초 |
| **300** | **−50%** | 4.2 칸/초 |
| 700 | −59% | 5.0 칸/초 |
| 2000 이상 | −75% (상한) | 6.3 칸/초 |

기준점은 **300층에서 1초 망설이면 게이지 절반**(사용자 확정). 수치는 `index.html` 상단
`TUNE` 한 곳에 모여 있고, 손맛 조정은 **회복량 12**를 먼저 만지면 전 구간이 함께 움직인다.

세제곱근 곡선이라 **난이도가 초반에 몰린다.** 완벽하게 정확히 눌렀을 때 도달 층수:

| 연타 속도 | 도달 |
|---|---|
| 2 칸/초 | 25층 (13초) |
| 3 칸/초 | 112층 |
| 4 칸/초 | 383층 |
| 5 칸/초 | 971층 |
| 6 칸/초 | 2013층 |

6.3칸/초 이상을 실수 없이 유지하면 이론상 죽지 않는다 — 2000층에서 감소량에 상한이
있기 때문이다(원작도 그렇다). 실제로는 그 속도에서 방향 판단이 먼저 무너진다.

## 랭킹

두 겹이다. **주력은 "내 기록"이고 명예의 전당은 덤이다.**

- **내 기록** — 이 기기의 `localStorage`. 오프라인에서도 항상 동작한다. 싱글·멀티 모두 남는다
- **명예의 전당(전체 순위표)** — 서버가 없으므로 공용 MQTT 브로커의 **retain 메시지 슬롯 10개**에
  순위표를 얹어 둔다(방명록과 같은 기법). 죽은 뒤에 비동기로 불러오며, **실패해도 게임에는 영향이 없다**

### 한계 (숨기지 않는다)

- retain 메시지는 영구 보관이 아니다. **브로커가 재시작하면 명예의 전당이 비워질 수 있다**
- 클라이언트가 자기 점수를 직접 올리는 구조라 **검증되지 않는다**
- 위 두 가지는 게임 안 명예의 전당 옆에도 한 줄로 적어 두었다

## 멀티플레이

- 2~8인. 방 코드 5자로 입장. 공용 MQTT 3중 브로커 폴백(OX 서바이벌과 같은 구조)
- **전원이 완전히 같은 계단을 오른다.** 방장이 시드를 뿌리고 모두 같은 난수열을 만든다 —
  실력 경쟁에 패턴 운이 섞이지 않게 하기 위해서다
- 각자 400ms마다 층수·생존 여부를 발행한다. 죽는 순간에는 즉시 알린다.
  **6초간 소식이 없으면 이탈로 보고 탈락 처리**한다
- 탈락하면 **즉시 관전**으로 넘어가고 최종 층수가 고정된다
- 마지막 한 명이 남으면 끝. 동시에 사라지면 **최종 층수가 높은 쪽이 우승**, 층수까지 같으면 공동 우승
- 결과 순위는 **오래 버틴 순**이다 — 더 높이 올라갔어도 먼저 떨어지면 아래에 놓인다
- **방장이 나가도 경기는 계속된다.** 각자의 죽음은 본인만 보고하고 다툴 여지가 없어서,
  시작 이후에는 모든 클라이언트가 같은 상태로 승자를 독립 계산한다.
  방장 권한은 대기실과 시작 신호까지만 필요하다

### 신뢰 모델 — 친구끼리 하는 방 전제

부정 방지를 하지 않는다. 두 경로가 열려 있다.

1. **가짜 층수 발행** — 공용 MQTT라 마음먹으면 아무 숫자나 보낼 수 있다
2. **관전자 코칭 / 계단 암기** — 전원이 같은 계단을 오르므로, 먼저 죽은 사람이 옆에서
   "다음은 왼쪽!"이라고 불러주면 그대로 통한다.
   그래서 **관전 화면에는 생존자의 앞으로 올 계단을 그리지 않는다**(층수와 생존 여부만 보여준다).
   다만 죽기 전까지 본 구간을 기억하는 것은 막을 수 없다

## 기술 메모

- 외부 의존은 mqtt.js CDN 하나뿐이고, **멀티를 고르거나 명예의 전당을 열 때만** 불러온다.
  **플레이 중에는 네트워크를 전혀 건드리지 않는다**
- 오가는 값이 층수와 생존 여부뿐이라 암호화할 것이 없다 → `crypto.subtle`을 쓰지 않고,
  따라서 https가 아니어도 된다
- 게이지는 프레임이 아니라 **실제 시계**로 닳는다. `requestAnimationFrame`에 물려두면
  탭을 옮겨둔 동안 게이지가 얼어붙어 안 죽는다 — 그건 이 게임의 규칙이 아니다
- 입력은 애니메이션 중에도 막지 않는다. 논리 상태를 즉시 갱신하고 그림이 따라온다
